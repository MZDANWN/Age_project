# 📅 Age Calculator

A Python script that calculates your exact age in Years, Months, and Days.

## How it Works

The script takes your birthdate as input and compares it with today's date.
It handles edge cases like month borrowing and leap years to ensure accurate results.

## Features

- Calculates age in Years, Months, and Days
- Validates input (invalid dates, future years, wrong month/day)
- Handles leap year edge cases
- Color-coded terminal output
